# Todd Deutsch — photography site

Static site (HTML, CSS, a little JavaScript). No install or framework needed.

## Editing

Gallery pages, the About page and the shared header/footer are generated by `build.py`.
Edit text, photo order and colors there, not in the `.html` files, then rebuild:

```bash
python3 build.py
```

`index.html` is the exception: its project cards are edited directly in the file
(the build only refreshes its header and footer).

## Previewing

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Layout

- `styles.css` — all styling. Landscape screens 900px+ wide scroll sideways; phones scroll down.
- `menu.js` — the header/footer menu.
- `hscroll.js` — turns the mouse wheel into sideways scrolling on wide screens.
- `assets/<gallery>/` — web-sized gallery photos (2000px); `assets/<gallery>.jpg` — home page cards.
